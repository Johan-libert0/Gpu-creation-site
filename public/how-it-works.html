Prompt jobs, visible terms

Approve the work before it begins.

GPU Foundry separates job approval, managed inference, buyer review, and payment. Render enables a separate x402 wallet checkout for direct text generation when its payment and inference settings are ready; approving marketplace work does not transfer funds.

01 / REQUEST

Set the terms

A buyer writes a prompt and proposes a title and payout. The prompt is sent to Hugging Face only after a provider accepts the job.

02 / ACCEPT

Generate a response

A marketplace provider accepts the request and the configured Hugging Face Inference Provider generates text. This does not use the marketplace provider's own GPU hardware.

03 / APPROVE

Review the result

The buyer reviews the output and approves it; marketplace job payment records remain unpaid. Direct text generation has a separate x402 checkout that charges 0.01 USDG per successful response when enabled.
